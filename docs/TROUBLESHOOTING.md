# 排障

| 症状 | 可以先检查 |
|---|---|
| 麦克风不录音 | 在系统设置的隐私与安全性中检查麦克风权限。 |
| 转写到了剪贴板 | 检查辅助功能权限，录音时选中目标文本框，并在转写完成前保持焦点。某些应用只支持剪贴板。 |
| 缺少 Key 或 Key 无效 | 在 DashVoice 设置中重新保存你自己的 DashScope API Key，核对服务地域和账户状态。 |
| 切换到 3.1 后请求失败 | 当前端点未接通 3.1，请在设置中选回 `qwen3-asr-flash`。 |
| 处理队列已满 | 等当前录音处理完成后再试。 |
| 请求返回 429 | 等一会儿再试，或检查自己的服务限流和额度。 |

可在本机运行 `scripts/diagnostics.sh` 查看诊断。提交 Issue 时只分享与问题有关的脱敏信息。
